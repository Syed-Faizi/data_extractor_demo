# Invoice & Document Data Extractor

Turn invoices and receipts (digital PDFs, scanned PDFs, phone photos) into clean, validated data in Excel — automatically.

**The problem:** teams spend hours typing invoice data into spreadsheets by hand. It's slow and full of typos.
**This tool:** upload a batch of documents, get one Excel file with every field filled in and every number checked.

## What it does

1. **Reads any document, page by page** – every PDF page is converted to an image and read with OCR (Tesseract), so digital and scanned pages go through the same path. Each page is wrapped in `<<PAGE n START>>` / `<<PAGE n END>>` markers and the pages are merged, so the model knows where every page begins and ends. The demo reads only the first 5 pages (`MAX_PAGES`) to keep token use and hallucination risk low.
2. **Extracts the fields** with a text LLM (no images are sent to the model) – vendor, invoice number, dates, bill-to, currency, subtotal, tax, total and every line item. Works across different layouts and labels ("Invoice No", "Bill number", "Receipt #"...).
3. **Validates the result** – flags missing fields, invalid dates, and math that doesn't add up (qty × price, line items vs subtotal, subtotal + tax vs total), so a human only checks the flagged ones.
4. **Exports to Excel** – a Summary sheet (one row per document) and a Line Items sheet.

Batch upload is supported, and one bad file never stops the rest.

## Run locally or with a local LLM

The extraction model is configurable. By default it uses the OpenAI API, but any OpenAI-compatible server works — so it can run **fully on your own machine** (Ollama, llama.cpp, vLLM) when documents can't leave your infrastructure.

```bash
# OpenAI
OPENAI_API_KEY=sk-...
LLM_MODEL=gpt-4o-mini

# Fully local with Ollama
OPENAI_BASE_URL=http://localhost:11434/v1
LLM_MODEL=qwen2.5:7b
```

## Quick start

```bash
pip install -r requirements.txt
# create a .env file with your settings (see "Run locally or with a local LLM" above)
python make_samples.py      # creates 3 fake sample invoices
python app.py               # open http://127.0.0.1:7860
```

Tesseract OCR must be installed:
- **Windows:** install from https://github.com/UB-Mannheim/tesseract/wiki, then set `TESSERACT_CMD=C:\Program Files\Tesseract-OCR\tesseract.exe` in `.env`
- **Mac:** `brew install tesseract`
- **Linux:** `sudo apt install tesseract-ocr`

## Project structure

```
extractor.py      # pipeline: text/OCR -> LLM -> validation
app.py            # Gradio web UI + Excel export
make_samples.py   # generates fake demo invoices
samples/          # demo documents (all fictional)
```

## Need this for your own documents?

The same approach works for medical forms, bank statements, purchase orders, shipping documents and more — custom fields, your own validation rules, and output straight to Excel, a database or your API. Feel free to reach out.

*All sample documents are fictional and generated by `make_samples.py`.*
